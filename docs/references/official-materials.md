## 使用规则

1. 原始文件保存在仓库外，或放入被 Git 忽略的本地资料目录。
2. 代码评审引用“文档名 + 版本 + 章节/字段”，不要提交大段转写内容。
3. 协议实现状态以 `src/network/proto/protocol_manifest.json` 和自动检查结果为准。
4. 规则或界面变化必须附上项目自行编写的影响说明和回归证据。
5. 官方资料与仓库实现冲突时，不直接覆盖生成代码；先按 `docs/maintainers/protocol-convergence-plan.md` 完成迁移评估。
