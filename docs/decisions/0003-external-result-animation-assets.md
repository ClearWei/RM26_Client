# ADR 0003：结算动画使用外部资源目录交付

- 状态：accepted
- 日期：2026-08-23

## 背景

三组结算动画共 270 帧，原图约 552 MiB。界面已经支持从应用目录附近的
`resources/images/resultpanel` 读取，也保留了 QRC 路径作为候选。把全部帧嵌入 QRC 会重复占用
包体，并生成约 835 MiB 的 C++ 资源源码，当前工具链无法稳定编译。

## 决策

- 结算动画按外部资源目录交付，不要求嵌入 QRC。
- CMake 安装树保留 `resources/images/resultpanel/<variant>` 目录结构，只安装 PNG 文件。
- QRC 继续承载体积较小、启动时必须存在的静态界面资源。
- 素材授权通过前，该安装规则只表示技术交付方式，不表示资源已经允许公开再分发。

## 结果

现有开发目录和文件系统兜底保持不变，未来安装包需要把动画目录放到客户端能够枚举的位置。
macOS Bundle、Windows 安装包和 Linux 安装树仍应分别做源码树外启动验证。

## 备选方案

- 全部嵌入 QRC：单文件部署简单，但编译输入和包体过大，已实际验证不可行。
- 删除动画：会改变现有赛场表现，不接受。
- 转为视频、雪碧图或压缩资源包：可能明显减小体积，但涉及播放逻辑和素材重编码，留作后续独立改造。

## 重新评估条件

当动画完成重编码、资源体积显著下降，或正式二进制发行需要单文件部署时，重新比较 QRC、资源包
和平台安装目录三种方案。
