# ADR 0004：历史比赛音效改为可选资源包

- 状态：accepted
- 日期：2026-08-23

## 背景

当前源码仍保留倒计时、比赛背景音乐、结算和击杀播报的 12 个文件名，但对应音频已经不在工作树。
内部历史显示，这批文件在 2026-05-31 被统一移入未使用目录，随后删除。现有播放入口会在文件缺失
时跳过，比赛状态、文字播报和操作链路不依赖这些音频。

直接从历史恢复文件无法解决来源和再分发权问题；用静音或重复音频占位又会掩盖真实缺口。

## 决策

- 这 12 个文件定义为可选比赛音效包，不作为客户端启动、通信或操作的必需资源。
- 保留现有文件名和播放入口；击杀语音同时支持 QRC 和应用目录附近的外部资源，便于团队使用自有
  录音恢复提示，无需修改播放逻辑。
- 默认源码归档不携带来源未确认的历史音频，也不提供伪造占位文件。
- 运行时资源门禁允许已登记的可选音效缺失；一旦文件进入 Git 索引，仍必须通过素材授权、文件有效性
  和 QRC alias 检查。

## 结果

不安装可选音效包时，客户端保持静默降级，界面、比赛状态和文字提示继续工作。需要音频提示的部署
必须自行提供已获授权的同名文件，并重新执行发布门禁和实际播放测试。具体文件名和放置方式见
[可选比赛音效包](../getting-started/optional-audio-pack.md)。

## 备选方案

- 从内部历史恢复旧音频：来源与再分发权未确认，不采用。
- 删除全部播放入口：会让后续自有语音包恢复变成代码改造，不采用。
- 提交静音占位文件：会让检查结果与真实产品能力不一致，不采用。

## 重新评估条件

团队完成一套自制或明确授权的比赛语音后，应将其作为独立资源包验收；若决定随源码发行，再把对应
文件纳入素材台账、QRC 和多平台播放测试。
