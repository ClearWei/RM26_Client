# 能量机关语音文件约定

以下文件名是客户端约定的能量机关语音入口。请使用团队自制或已经取得再分发授权的正式语音；
客户端会先检查文件是否存在，缺少语音时只记录警告，不会打断正在播放的其他音效。

| 文件名 | 播报内容 |
| --- | --- |
| `rune_small_remaining_1.mp3` | 小能量机关剩余 1 次机会 |
| `rune_small_remaining_2.mp3` | 小能量机关剩余 2 次机会 |
| `rune_large_remaining_1.mp3` | 大能量机关剩余 1 次机会 |
| `rune_large_remaining_2.mp3` | 大能量机关剩余 2 次机会 |
| `rune_large_remaining_3.mp3` | 大能量机关剩余 3 次机会 |

五个文件必须分别录制或导出，不能让大、小能量机关共用同一份语音。
